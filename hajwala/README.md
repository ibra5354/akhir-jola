# هجولة 🚗💨

لعبة سيارات ثلاثية الأبعاد في المتصفح بروح خليجية: ليل الحي، ساحة التفحيط، الطريق السريع، والبر.

- `index.html`: اللعبة كاملة في ملف واحد (three.js من CDN).
- `source/`: الكود مقسّم. `python3 build.py` يجمعه في `build/hajwala.html`.
- `source/test/`: اختبارات Playwright (فيزياء، أطوار، لمس، أونلاين).

## التحكم
- الكيبورد: WASD أو الأسهم · مسافة هاند بريك · Shift نيترو · H هرن · C كاميرا · R رجّع السيارة · E تفاعل · P تصوير · Esc إيقاف
- الجوال: بالعرض، دركسون بالسحب يسار، والأزرار يمين
- يد التحكم مدعومة
